# AGENTS.md

Instructions for AI coding agents (Claude Code, Codex, Cursor, Aider, etc.) working in this repo.

## What this is

`avby-convert` is a free, non-commercial Chrome/Firefox extension (Manifest V3) that adds approximate USD prices next to BYN prices on `*.av.by` car listings. Belarusian law banned USD price displays on classifieds; this extension restores them client-side without any network requests or telemetry.

The exchange rate is read from the `.main-converter` element on the page itself — never from external APIs.

## Quick start

```bash
npm install
npm test           # 49 unit tests, fast
npm run typecheck  # tsc --noEmit
npm run build      # produces dist/chrome and dist/firefox
npm run package    # also produces avby-convert-{chrome,firefox}.zip
npm run build:dev  # watch mode for development
```

Load `dist/chrome/` (or `dist/firefox/manifest.json`) as an unpacked extension to test against `cars.av.by`.

## Repo structure

```
src/
  core/         Pure logic: types, parse, format, convert. 100% unit-tested.
  config/       Default groups + rules + merge with user overrides.
  storage/      Typed wrapper over chrome.storage.local.
  engine/       Content script: rate-watcher, dom-walker, observer, inserter, orchestrator.
  ui/popup/     Popup (mode, snap, order controls).
  ui/options/   Options page (3 tabs: Правила / Дополнительно / О расширении).
  manifest/     chrome.json and firefox.json (built-time selected by build.mjs).
  background/   Empty MV3 entry-point placeholder.
  shared/       Cross-browser API shim (browser ?? chrome).
  icons/        16/48/128 PNGs (procedurally generated by scripts/make-icons.mjs).

tests/          vitest tests for core/ and config/ — pure logic only.
build.mjs       esbuild script producing both Chrome and Firefox bundles.
scripts/        zip.mjs (packaging), make-icons.mjs (placeholder icons).
```

## Conventions

- **TypeScript strict**, including `noUncheckedIndexedAccess`. Treat `arr[i]` as possibly undefined.
- **No `innerHTML`**. A pre-commit hook blocks it. Use `createElement` + `textContent` for all DOM construction (XSS hygiene).
- **No network requests, no telemetry**. The extension reads the rate from the page itself. Don't add fetch/XHR/external APIs anywhere.
- **No frameworks**. Vanilla DOM. Don't add React/Vue/etc.
- **Commit messages in ASCII**. PowerShell 5.1 on Windows mangles non-ASCII when piped to `git -m`. Use `->` instead of `→`, etc.
- **Russian UI text** in popup/options is intentional — primary audience is Belarusian. Preserve Cyrillic in source files (write via the Write tool, not `echo` from PowerShell).

## Platform note (Windows)

Bash on the maintainer's Windows machine lacks `git`/`npm`/`node` (returns exit 127). Use **PowerShell** for all CLI invocations. Forward-slash paths work in source code; PowerShell tolerates both.

## Testing

- `core/` and `config/` are unit-tested with vitest. Add tests when modifying parsing, formatting, conversion, or merge logic.
- `engine/` (DOM-side) has no automated tests — verify via manual browser smoke against live `cars.av.by`.
- `ui/` (popup, options) — manual click-through verification.

Run `npm test` after any change to `core/` or `config/`. Run `npm run typecheck` after any TS change.

## Architectural guarantees

- **Idempotent conversion**: `applyConversion` can be called multiple times on the same element without duplicating USD labels (uses `data-avby-converted` attribute).
- **Fully reversible**: `removeConversion` returns the DOM to its original state — including unwrapping the `[data-avby-original]` marker.
- **Reactive to text changes**: when a converted element's BYN text changes (e.g., AJAX update), the DJB2 hash check in `originalTextChanged` triggers re-conversion.
- **First-rule-wins**: when multiple rules match the same element, the first rule (by order in `default-rules.ts`) wins. Logs a warning.
- **Storage shape stable**: `StoredConfig` in `core/types.ts` is the single source of truth. Don't add fields without considering migration.

## What NOT to do

- Don't add network requests of any kind.
- Don't add new permissions to manifests beyond `storage` and `*://*.av.by/*` matches.
- Don't store any user-identifying data.
- Don't move BYN-related logic into `engine/` — keep parsing/formatting in `core/` so it stays testable.
- Don't break `removeConversion` reversibility — every host class added must be in the `HOST_CLASSES` list.

## Common tasks

- **Add a new selector**: edit `src/config/default-rules.ts`, append to `DEFAULT_RULES`. Pick `groupId` from existing groups (or add a new group in `default-groups.ts`).
- **Add a new value format**: add a group in `default-groups.ts` with `match` (regex source string), `captures` (array of capture names), `format` (template like `~{amount|usd} в месяц`).
- **Tweak USD formatting**: edit `src/core/format.ts`. Add a vitest test in `tests/format.test.ts`.
